# RoboZak AI

An experimental project to explore modern control and interaction for the RoboZak robot.

The intended approach is to use Python on a computer for the user interface, communication, and possible AI features. Firmware for the robot controller will be selected after the hardware and its interfaces have been confirmed. Movement control and safety limits should remain deterministic and independent of AI output.

## Project layout

- [docs](docs/README.md) — requirements, decisions, and project notes.
- [hardware](hardware/README.md) — inventory, measurements, and electrical design.
- [firmware](firmware/README.md) — future robot controller firmware.
- [software](software/README.md) — future Python software running on a computer.

This repository is at an early planning stage; the hardware configuration and software interfaces are not yet established.
